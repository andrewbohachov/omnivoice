# OmniVoice

[English](README.md) | **[Русский](README_RU.md)**

Голосовой ввод и диктовка промптов для терминальных AI-агентов (Antigravity CLI, Claude Code, Codex, Aider).  
**Без сторонних API-ключей. Управление через Caps Lock. Адаптировано под IT-терминологию.**

OmniVoice прозрачно оборачивает вашего консольного AI-помощника в псевдотерминал, позволяя диктовать длинные и сложные технические задачи голосом вместо ручного набора сотен символов на клавиатуре.

---

## Основные возможности

* **Создано специально для консольных агентов:** Поддерживает `agy` (Antigravity CLI), `claude` (Claude Code), `codex`, `aider` и обычный `bash`.
* **Удобное переключение через Caps Lock:** Одно нажатие `Caps Lock` — начинается запись голоса; повторное нажатие `Caps Lock` — запись останавливается, а текст мгновенно вставляется в строку ввода агента.
* **Понимание IT-терминологии:** Точно распознаёт английские термины (`API`, `FastAPI`, `Redis`, `Git`, `Docker`, `pull request`, `pytest`) прямо внутри русской речи.
* **Интерактивный мастер при первом запуске:** Меню со стрелочками для выбора удобного движка:
  * **Whisper Small (Рекомендуется):** ~480 МБ, 100% оффлайн, оптимальная скорость (~2 сек) и точность в коде.
  * **Google Speech:** 0 МБ на диске, быстрый облачный API, 0 МБ оперативной памяти, без API-ключей.
  * **Whisper Turbo (Large-v3):** ~1.6 ГБ, максимальная точность для мощных ПК и рабочих станций.
* **Интерактивный выбор агента:** Если запустить `omnivoice` без аргументов, откроется список установленных AI-агентов для быстрого выбора. Также можно запускать напрямую: `omnivoice agy` или `omnivoice claude`.
* **Чистая архитектура Linux:** Работает одинаково надёжно и под Wayland, и под X11 через нативный опрос событий клавиатуры `evdev`.

## Установка

### Вариант 1: Установка одной командой через cURL (Рекомендуется)

Автоматически устанавливает системные пакеты (`ffmpeg`, `libportaudio2`), настраивает права доступа к клавиатуре, загружает модель Whisper Small и регистрирует глобальную команду `omnivoice`:

```bash
curl -fsSL https://raw.githubusercontent.com/andrewbohachov/omnivoice/main/install.sh | bash
```

### Вариант 2: Готовый deb-пакет для Debian / Ubuntu (.deb)

Скачайте готовый `.deb` пакет и установите через APT:

```bash
sudo apt install ./omnivoice_0.1.0_all.deb
```

### Вариант 3: Ручная установка из исходников (Git / pip)

```bash
# 1. Установка системных зависимостей (Debian / Ubuntu / Mint)
sudo apt update
sudo apt install -y python3 python3-pip python3-venv ffmpeg libportaudio2

# 2. Клонирование репозитория и установка пакета
git clone https://github.com/andrewbohachov/omnivoice.git
cd omnivoice
pip install -e .

# 3. Глобальный симлинк
sudo ln -sf $(which omnivoice) /usr/local/bin/omnivoice
```

## Быстрый запуск

### 1. Запуск нужного агента

Запуск напрямую с именем команды:
```bash
# Запуск Antigravity CLI
omnivoice agy

# Запуск Claude Code
omnivoice claude

# Запуск Codex CLI
omnivoice codex

# Запуск Bash
omnivoice bash
```

Или запустите `omnivoice` без параметров для выбора агента из меню:
```bash
omnivoice
```

### 2. Диктовка промптов через Caps Lock

1. Находясь в строке ввода агента, нажмите **`Caps Lock`** один раз.
2. В терминале отобразится `[● REC] Идёт запись...`. Произнесите вашу задачу в микрофон:
   > *«Сделай рефакторинг API на FastAPI, добавь кэширование в Redis и проверь сборку через npm run build»*
3. Нажмите **`Caps Lock`** второй раз для остановки записи.
4. Распознанный текст мгновенно появится в строке ввода агента.
5. Проверьте текст, при необходимости отредактируйте и нажмите **`Enter`** для отправки!

## Параметры запуска

```
omnivoice [ПАРАМЕТРЫ] [КОМАНДА...]

Аргументы:
  команда                      Команда AI-агента для запуска (по умолчанию: интерактивное меню)

Параметры:
  --engine {small,google,turbo}  Выбор движка распознавания речи
  --lang {en,ru}                 Язык интерфейса (по умолчанию: ru)
  --setup, --config              Повторный запуск мастера выбора движка
  -h, --help                     Показать справку
```

### Примеры:
```bash
# Запуск Claude Code со стандартным движком
omnivoice claude

# Запуск Antigravity CLI с легковесным Google Speech (0 МБ ОЗУ)
omnivoice --engine google agy

# Смена движка через интерактивное меню
omnivoice --config
```
